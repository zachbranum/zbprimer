# How I built this site

<p id="build-heading">This page explains the implementation choices behind the project structure, layout, and publishing workflow.</p>

<h2>Tool stack and structure</h2>
<ul>
  <li>Static site generator: Jekyll.</li>
  <li>Deployment target: GitHub Pages.</li>
  <li>Styling: custom CSS with Virginia Tech-inspired maroon and orange palette.</li>
  <li>Accessibility baseline: semantic landmarks, skip link, focus styles, and ARIA labels.</li>
</ul>

<h2>Agent involvement</h2>
<p>The repository scaffold, accessible layout, page structure, and build workflow were generated with assistance from a coding agent. The conceptual framing and substantive content are owned by the site author, who will revise and extend all page content.</p>
